# .gitignore

A small collection of ready-made `.gitignore` files that I reuse across my projects. Copy one into a new project and stop committing build folders, IDE files and secrets by mistake.

## What is inside

| File | For |
|---|---|
| [`Android/.gitignore`](Android/.gitignore) | Android Studio and Gradle projects |
| [`NodeJS/All/.gitignore`](NodeJS/All/.gitignore) | Node.js projects, any editor |
| [`NodeJS/Webstorm/.gitignore`](NodeJS/Webstorm/.gitignore) | Node.js projects opened in WebStorm |

## How to use

1. Pick the file you need from the table above.
2. Download it into the root of your project, for example:

```bash
curl -o .gitignore https://raw.githubusercontent.com/p32929/.gitignore/master/NodeJS/All/.gitignore
```

3. Commit it before your first `git add .`, so the ignored files never enter your history.

Need one for another language? [github/gitignore](https://github.com/github/gitignore) has one for nearly everything.
