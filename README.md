# .gitignore

A small collection of `.gitignore` files I reuse across projects, so I stop hunting for them.

| Path | For |
|---|---|
| [`Android/.gitignore`](Android/.gitignore) | Android Studio / Gradle projects |
| [`NodeJS/All/.gitignore`](NodeJS/All/.gitignore) | Node.js projects, editor-agnostic |
| [`NodeJS/Webstorm/.gitignore`](NodeJS/Webstorm/.gitignore) | Node.js projects opened in WebStorm |

## How to use

Copy the one you need into the root of your project:

```bash
curl -o .gitignore https://raw.githubusercontent.com/p32929/.gitignore/master/NodeJS/All/.gitignore
```

If you need something not here, [github/gitignore](https://github.com/github/gitignore) has one for nearly every language.
